# SkillSwap 🔄

SkillSwap is a simple skill-sharing platform designed to help people connect, learn, and exchange skills with each other.

## 💡 About the Project

SkillSwap allows users to:
- 🔎 Find people with skills they want to learn
- 🎓 Offer their own skills to others
- 👤 View creator profiles
- 📊 Manage their services through a dashboard

The project focuses on creating a simple, friendly, and easy-to-navigate interface.

## 📄 Pages

- **Home** – Introduction to SkillSwap
- **Index** – Explore available skills
- **Offer a Skill** – Share your own skills
- **Creator's Profile** – View information about skill providers
- **Dashboard** – Manage services and activities

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
